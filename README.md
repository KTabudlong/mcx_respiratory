# mcx_respiratory

Class announcement board for the Respiratory Therapy program at Malcolm X College.
React + TypeScript (Vite) on GitHub Pages, with Firebase (Spark plan) for auth and data.

## Local development

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in the Firebase web config.
3. `npm run dev`, then open the URL Vite prints (ends in `/mcx_respiratory/`).

Checks: `npm run lint`, `npm run format`, `npm run types:check`, `npm test`, `npm run build`.

Pushing to `main` deploys to https://ktabudlong.github.io/mcx_respiratory/.
